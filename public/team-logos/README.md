## 이미지 요구사항

- **포맷**: PNG (투명 배경 권장)
- **권장 크기**: 500x500px ~ 1000x1000px
- **파일 크기**: 각 100KB 이하 권장
- **배경**: 투명 또는 검은색

## 업로드 방법

1. Figma Make UI에서 `/public/team-logos/` 폴더 생성
2. 연도별 하위 폴더 생성 (2020, 2021, ..., 2025)
3. 각 연도 폴더에 해당하는 팀 로고 업로드

## 작동 방식

- 로고가 있으면: **500x500px 크기로 화면 중앙에 표시**
- 로고가 없으면: **팀 이름 텍스트로 fallback**
